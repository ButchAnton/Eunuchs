Hello from Eunuchs

This page is served by /bin/httpd running inside the RISC-V guest, over the kernel's own TCP/IP stack and virtio-net driver.

Live kernel state

  • /proc/net/tcp (TCP connections, including this one)
  • /proc/net/stats (protocol counters)
  • /proc/net/dev and /proc/net/arp
  • /proc/threads, /proc/cpus, /proc/procs, /proc/meminfo
  • everything in /proc
